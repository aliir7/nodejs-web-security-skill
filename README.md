# Node.js Web Security Skill

Enterprise-grade, portable AI security instructions for Node.js web applications.

## Install with npx

```bash
npx nodejs-web-security-skill init .
```

## Platform adapters

```bash
npx nodejs-web-security-skill install claude .
npx nodejs-web-security-skill install codex .
npx nodejs-web-security-skill install gemini .
npx nodejs-web-security-skill install cursor .
npx nodejs-web-security-skill install copilot .
```

Check an existing project:

```bash
npx nodejs-web-security-skill doctor .
```

## Core invariant

> Authentication answers “Who is this user?”, Authorization answers “What may this user do?”, and Ownership answers “Does this specific resource belong to this user?”

## Supported stacks

- Express + Mongoose
- NestJS + TypeORM
- NestJS + Prisma
- Next.js + Drizzle
- React
- TypeScript / JavaScript

## Scope

Defensive web application security and secure software development for Node.js stacks. The canonical source is `SKILL.md`; detailed material lives under references, examples, checklists, rules, and templates.
